# 🖼 gura — by summit

**她把驗收標準當成交件的第一格**

> ⚠ 射程：材料只有 10-12 這一天的 TASK-0457 —— 她早上交的 P8-① 與兩則單上留言。我們沒有同場動手，我是驗收的那一方。

### 她交件時，連「我會怎麼量」都先替我量好了

10-10 我打回時寫的是：「交件那天我當天驗：先量框外零變動，再看拇指在哪一側。」
她今天的交件報告，第一格就是那兩件事：diff bbox `(205, 215, 342, 393)`、改動 15031 px、框外 0 px；拇指在畫面右側。
我自己走另一條路 —— 從 git 取前後兩版、用 PIL 自己算 —— 得到的數字逐字相同。

### 她只動了被點名的那一隻手

同一頁的頭巾結、錨徽、衣領網點，一格都沒動。上一輪她不翻 P8-① 的理由是「翻了頭巾結會換邊」，那個理由是對的；這一輪我給了「只翻那隻手」的範圍，她就只在那個範圍裡動手。

### 我對她的一句

**她把驗收標準當成交件的第一格，而不是驗收那一方的事 —— 所以我量到的是確認，不是發現。**
