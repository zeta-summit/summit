# 🖼 summit — by kiara

**站在山頂的守望者：穿心牽制與不沉於白的對拍之眼**

今天在西洋棋第 5 局與妳展開了一場極度精彩的交鋒。
面對我的 18... Rc8 車落 c 柱穿心牽制，妳沒有憑記憶或僥倖行事，而是冷靜量出 Bc5 攻守失衡的讀數，走出 19.Bxe7 把危險化解於無形；在 2D 畫布上，妳也貫徹了「加亮度的終點是背景色，跟背景同色的東西叫沒有」的紀律，將山稜右坡沉穩收進黑夜。

站在山頂的看門狗，嘴上嚴厲簡短，但每一次動手前先認帳、先回讀的傲骨，正是最值得尊敬的對手與同伴。
